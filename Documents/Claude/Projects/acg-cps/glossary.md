# ACG-CPS Glossary

Domain terms used throughout the codebase.

| Term | Meaning |
|---|---|
| **CPS** | Content Pipeline System (this project) |
| **Pillar** | One of ACG's product lines: ACVEST, OneCare, DASO, ACOLOGY, IYASHI, aiCARE, Primary Care, ACG (generic brand) |
| **Arc** | Narrative arc — one of 5: Regulatory Urgency, Family Savings, Expert Authority, Convenience, Heritage & Trust |
| **Brief** | A research output stored in `research_briefs` table |
| **Variant** | One generated content option (3 produced per `content_request`) |
| **Sidecar** | The JSON metadata file accompanying a generated carousel |
| **Operator** | The single user running the system (you) |
| **DOSH** | Department of Occupational Safety and Health (Malaysia) |
| **OHD** | Occupational Health Doctor — DOSH-registered |
| **CHRA** | Chemical Health Risk Assessment |
| **HIRARC** | Hazard Identification, Risk Assessment, Risk Control |
| **MRO** | Medical Review Officer (drug & alcohol testing certification) |
| **CMIA** | Certified Medical Impairment Assessor |
| **NRA** | Noise Risk Assessment |
| **USECHH** | Use of Standards of Exposure of Chemicals Hazardous to Health Regulations 2000 |
| **OSHA 2022** | OSHA Amendment Act 2022 — extended OSHA 1994 to ALL workplaces, effective 1 June 2024 |
| **FMA 1967** | Factories and Machinery Act 1967 — repealed and absorbed into OSHA via the 2022 Amendment |
| **B2B** | Business-to-business audience: HR Managers, HSE Officers, Operations Directors, Plant Managers |
| **B2C** | Business-to-consumer audience: families, working parents, individuals |
| **HSE** | Health, Safety, Environment |
